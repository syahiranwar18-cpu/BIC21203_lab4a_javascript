## Brief Explanation
This repository contains the completed tasks for Lab #4a, focusing on client-side scripting using JavaScript. The tasks involve DOM manipulation, event listeners (`addEventListener`), input validation using conditional statements, and dynamic element generation using loops.

## Structure of Repository
* `Q1/` - Interactive Text Changer (`Q1.html`, `script.js`)
* `Q2/` - Smart Number Validator (`Q2.html`, `script.js`)
* `Q3/` - Dynamic Number Generator (`Q3.html`, `script.js`)

## Instructions to Run
1. Clone or download this repository to your local computer.
2. Navigate to any question folder (e.g., `Q1`).
3. Open the `Q1,Q2,Q3.html` file in any modern web browser (Google Chrome, Microsoft Edge, etc.) to view and test the output.
